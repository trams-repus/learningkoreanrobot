# Play 스토어 등록 안내 (한글대작전)

## 1. 업로드 키 만들기 (한 번만, 직접)
업로드 키는 비밀이라 저장소에 올리지 않는다. Java가 있는 PC에서:

```
keytool -genkeypair -v -keystore upload.keystore -alias upload -keyalg RSA -keysize 2048 -validity 10000
```

비밀번호 하나(키 저장소와 키에 같은 것)를 정해 입력한다. 파일과 비밀번호는 잃어버리지 않게 따로 보관.

## 2. GitHub Secrets에 넣기
저장소 Settings → Secrets and variables → Actions → New repository secret
- `ANDROID_UPLOAD_KEYSTORE_BASE64`: `base64 -w0 upload.keystore` 결과 (Windows: `certutil -encode upload.keystore out.txt` 후 머리·꼬리 줄 빼고 붙여넣기)
- `ANDROID_UPLOAD_KEYSTORE_PASSWORD`: 정한 비밀번호

그 뒤 main push(또는 Actions에서 "안드로이드 APK" 수동 실행)마다 `hangul-daejakjeon-aab` 아티팩트로 AAB가 나온다.

## 3. Play Console
- 앱 만들기: 이름 "한글대작전", 게임, 무료(인앱 상품 포함). Play 앱 서명(Google이 서명 키 관리) 사용.
- 개인정보처리방침 URL: https://trams-repus.github.io/learningkoreanrobot/privacy.html
- 대상 연령: 5세 이하, 6~8세 → 가족 정책 적용. 광고 없음("광고 포함: 아니요").
- 인앱 구매: "예". 1회 구매(비소모성) 상품 1개 `hangul_all_stages`(11단계부터 전체 열기)뿐. 구독·소모성 상품·광고 없음. 구매 버튼은 보호자 확인(두 자리 곱셈 문제, 숫자 패드 입력) 뒤에만 나온다.
- 데이터 보안 양식: 앱이 수집·공유하는 데이터 "없음". 결제·구매 내역은 Google Play가 자체 개인정보처리방침에 따라 처리하고, 앱은 영수증 검증 서버를 쓰지 않아 기기 정보를 제3자에게 보내지 않는다. 학습 기록·구매 상태는 기기 안에만 저장(외부 전송 없음). 앱은 마이크·카메라·위치 권한을 요청하지 않는다(부모 목소리 녹음은 웹판에만 있음). 결제 내역 항목을 신고할지는 Play Console 안내로 한 번 더 확인할 것. 계정 없음 → 데이터 삭제 요청 항목 해당 없음.
- 콘텐츠 등급 설문: 폭력 = 만화풍 로봇·공룡 전투(피 없음). 디지털 상품 구매 = 예. 사용자 간 상호작용·위치 공유 = 없음.
- 개인 계정 조건: 비공개 테스트에 테스터 12명 이상, 14일 연속 참여 후 프로덕션 신청 가능.

## 4. 결제 관련 준비
- [ ] Play Console → 수익 창출 → 인앱 상품에서 `hangul_all_stages`(비소모성) 만들고 활성화
- [ ] 가격 정하기 (가격: Play Console에서 정함)
- [ ] 결제 프로필(판매자 계정) 설정
- [ ] 내부 테스트 트랙에 AAB 올리고, 설정 → 라이선스 테스트에 테스터 계정 추가
- [ ] 구매 테스트: 보호자 확인 → 구매 → 11단계 열림 확인
- [ ] 대기 중 결제 테스트: "느리게 승인/거부되는 테스트 카드"로 대기 상태 표시와 승인 후 잠금 해제 확인
- [ ] 구매 복원 테스트: 앱 삭제 후 재설치(또는 다른 기기)에서 "구매 복원"으로 다시 열리는지 확인
- [ ] 웹 테스트판(GitHub Pages)은 결제 없이 모든 단계가 열려 있는지 확인

## 스토어 문구 (초안)
- 짧은 설명(80자): 로봇과 함께 자음·모음을 끌어 맞춰 한글 단어를 만드는 어린이 한글 게임
- 자세한 설명:

  한글을 막 시작하는 아이를 위한 작은 한글 조합 게임입니다.
  단어를 들려주면 아이가 자음과 모음을 끌어다 초성·중성·종성 순서로 글자를 만들고, 맞힐 때마다 로봇(또는 마법소녀)이 공룡을 물리칩니다.
  · 음절이 완성될 때마다 소리 내어 읽어 줍니다
  · 빠르게 연속으로 맞히면 콤보, 에너지를 모아 필살기
  · 헷갈리는 함정 글자로 자연스럽게 구별 연습
  · 1~10단계 무료. 11단계부터는 1회 구매(가격: Play Console에서 정함)로 끝없이 이어지며, 10단계마다 새 지역이 열립니다
  · 구독·추가 결제 없음. 구매는 보호자 확인을 거쳐야 하며, 새 기기나 재설치 후 "구매 복원" 가능
  · 광고, 로그인 없음. 학습 기록은 기기 안에만 저장
- 스크린샷: 폰 세로 최소 2장(권장 4장+), 아이콘 512×512, 그래픽 이미지 1024×500 필요.
