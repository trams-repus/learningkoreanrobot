# 어휘와 그림 계획

최종 목표: 레벨을 모두 합쳐 **3,000단어**, 모든 단어에 같은 그림체의 그림. 여러 세션에 걸쳐 레벨 하나씩 끝까지 완성한다.

## 레벨과 목표 수

| 레벨 | 어휘팩 ID | 대상 | 목표 | 지금(검수 완료) | 성격 |
|---|---|---|---|---|---|
| L1 기초 | `4-6` | 4~6세 | 700 | **700** (2026-09-29 완료) | 눈에 보이는 사물·동물·음식·몸, 쉬운 행동·상태. 1~3음절 위주 |
| L2 확장 | `7-8` | 7~8세 | 1,000 | **1,002** (2026-09-29 완료) | 장소·직업·계절·감정, 받침·쌍자음·겹모음 단어 늘림. 2~4음절 |
| L3 심화 | `9+` | 9세~ | 1,300 | **1,310** (2026-09-29 완료) | 긴 단어, 겹모음·어려운 받침, 조금 추상적인 말(그림으로 보일 수 있는 것만) |

- 부모 설정의 어휘팩이 레벨이다. 한 팩에서 조건에 맞는 단어가 8개보다 적으면 다른 팩의 같은 조건 단어를 더한다 (`stageWords`).
- 전투 단계(`stages.ts`)는 팩 안에서 음절 수와 조립 단계(받침 없음 → 받침 → 쌍자음·ㅐ → 겹모음)로 고른다. 레벨이 곧 단계가 아니다.

## 단어 고르는 기준 (우선순위)
1. **그림으로 뜻을 알 수 있는 말**을 먼저. 한 장의 그림으로 뜻이 헷갈리지 않아야 한다.
2. 아이가 일상에서 듣고 쓰는 말. (공식 기초 어휘 목록 대조는 아직 못 했다: `sourceStatus: '임시 선정'`)
3. 조립틀이 지원하는 표기: 겹받침(ㄳ ㄵ ㄶ ㄺ ㄻ ㄼ ㄽ ㄾ ㄿ ㅀ ㅄ)이 든 단어는 아직 넣지 않는다. 겹모음(ㅘ ㅙ ㅚ ㅝ ㅞ ㅟ ㅢ)은 2026-09-29부터 지원 (`mixed` 틀, 31단계부터 출제).
4. 소리와 표기가 다른 단어는 넣되 `soundMatchesSpelling: false`로 표시한다(초기 독립 조합에서 뒤로 미룸). `src/hangul/pronunciation.ts`가 규칙으로 판정하고, 규칙으로 못 잡는 합성어 된소리는 `SOUND_EXCEPTIONS`에 적는다. 테스트가 어휘 표시와 판정이 같은지 검사한다.

## 넣지 않는 말 (예외 목록)
그림 한 장으로 뜻을 정하기 어렵거나 다른 뜻과 헷갈리는 말. 넣는다면 여기에 까닭과 함께 적는다.

| 말 | 까닭 | 처리 |
|---|---|---|
| 배 | 과일·몸·탈것 세 뜻 | 넣지 않음 (보트·배꼽은 따로) |
| 눈(雪) | 이미 '눈(눈동자)'이 있음 | 눈사람으로 대신 |
| 풀 | 식물·붙이는 풀 | 넣지 않음 |
| 이 | 이빨·지시어 | '이빨'로 넣음 |
| 밤 | 저녁·열매 | 넣지 않음 |
| 차 | 자동차·마시는 차 | '자동차'로 넣음 |
| 다리(橋) | 이미 '다리(몸)'이 있음 | 넣지 않음 |
| 사랑, 생각, 약속, 시간 같은 추상어 | 그림으로 뜻이 정해지지 않음 | L3에서도 그림 가능할 때만 |
| 앉다, 짧다, 닭, 흙, 읽다, 많다 | 겹받침 (조립틀 미지원) | 겹받침 지원 뒤 |

뜻이 여럿이지만 넣은 말은 그림 안내에 뜻을 하나로 정했다: 말(동물), 새(동물), 벌(곤충), 감(과일), 김(먹는 김), 무·가지·파(채소), 목(몸), 볼(얼굴), 성(건물), 쓰다(글씨 쓰기), 타다(말 타기), 잠자리(곤충), 김(먹는 김), 탑(돌탑), 새(파랑새, 참새와 구별).

## 한 단어를 완성했다고 보는 조건
1. 표기: 조립틀로 낼 수 있음 (`isSupportedWord`), 분해 → 재조합이 같은 단어 (`tests/vocab.test.ts`)
2. 함정 자모: 단어의 모든 자모에 함정 표가 있음 (`TRAPS`, 겹모음 포함)
3. 소리: `soundMatchesSpelling`이 발음 판정과 같음, 음성 목록 항목이 있음 (기기 음성으로 읽음)
4. 그림: 스타일 가이드(`docs/picture-style.md`)를 따른 SVG, 글자 없음, 76px에서 알아볼 수 있음 (사람이 연속 장면으로 확인)
5. 게임 안 표시: 단어 그림 칸에 그림이 뜸 (`tests/pictures.test.ts`: 어휘 전부 그림 있음)
위를 모두 통과한 단어만 `src/content/vocab.ts`에 넣는다 (넣으면 곧 출제된다).

## 작업 순서 (다음 세션도 같은 방식)
1. `docs/vocab-candidates-<레벨>.json`에 후보(단어·영역·핵심/권장·그림 안내)를 적는다. 테스트가 조립 가능·중복 없음을 검사한다.
2. 영역별로 나눠 그림 묶음 파일 `src/content/pictures/<레벨>-<영역>.ts`를 만든다 (여러 명이 동시에 그려도 파일이 겹치지 않는다).
3. `node scripts/picture-sheet.mjs`로 한 장에 모아 검수한다. 메인 작업자가 무작위로 골라 다시 본다.
4. 통과한 그림만 `pictures.ts`에 등록하고 단어를 `vocab.ts`에 넣는다. 후보 JSON에서는 뺀다.
